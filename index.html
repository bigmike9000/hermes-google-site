Hermes Personal Assistant

A personal assistant operated by Michael Fang for his own Google accounts.

This installation helps Michael find information in Gmail, organize Calendar and Tasks, and work with files in Drive, Docs, and Sheets. It is a private installation of the open-source Hermes Agent software, not a public service or an official website for that project.

How Google access works

Michael connects each account through Google's authorization screen. The assistant accesses only the services covered by the permissions granted for that account.

  • Gmail: read-only access for finding and summarizing messages. This integration does not request permission to send, delete, or modify email.
  • Calendar and Tasks: access to read and manage schedules and task lists as requested.
  • Drive, Docs, and Sheets: access to find, read, and work with files as requested.
  • Account identity and contacts: access to identify the connected account and look up contact information.

Private use only

This website provides application and privacy information. It has no Google sign-in form and does not display account data. It does not offer access to the assistant to visitors.
